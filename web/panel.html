      Connecting

      Control panel password

      Find it in Gotify under Plugins → Gotify Commander, in the Control panel password section. It is generated the first time the plugin is enabled and stays the same after restarts.

      To use your own, set web_password in the plugin configuration. Empty it again to go back to the generated one.

      This tab keeps the password until you close it, or until you lock the panel with the padlock in the header.

      The session is kept in this browser for 24 hours. The ✕ Clear button above it removes it now.
